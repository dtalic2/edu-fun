# edu-fun

An interactive educational quiz game covering math, science, and general knowledge.

## Usage

```bash
python quiz.py
```

Choose a category (Math, Science, General Knowledge, or Random Mix), answer 5 multiple-choice questions, and see how you score.

## Running Tests

```bash
pytest test_quiz.py -v
```

## Project Structure

- `quiz.py` — Main quiz application
- `test_quiz.py` — Unit tests
